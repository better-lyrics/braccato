The karaoke highlight runs on the compositor. Each timed word's overlay now holds a static soft-edged mask over a counter-translated copy of its text, so the sweep is two `translate` animations instead of custom properties driving a `background-clip: text` gradient the main thread repainted every frame; with the letter wave on, the per-letter `mask-position` sweeps go the same way. The glow is a second masked copy carrying a text shadow that never changes, faded by opacity instead of a shrinking `drop-shadow` filter, so it forces neither a paint nor a re-layerization per frame. The overlay's own background is no longer text-clipped, which had made it repaint whenever a letter moved. Words that can fragment across lines (long or wrap-broken words, bidi-sensitive rows) and image highlights keep the gradient path, and `blyrics-composited-highlight = false` keeps it everywhere for a theme that replaces the karaoke effect through `--lyric-transition-amount-*`. On the composited path the glow reads `--blyrics-highlight-glow-radius-*` and `--blyrics-glow-color`; the `--blyrics-highlight-glow-filter-*` overrides apply only to the gradient path.
